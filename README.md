# FocusForge ⚡

Besiege Prokrastination – bewusst und unterbewusst. Eine zweisprachige (DE/EN), offline-fähige Web-App mit 18 wissenschaftlich fundierten Methoden.

## Features
- 🎯 **One Thing** – automatisch der wichtigste nächste Schritt
- 🧰 **18 Methoden**: Pomodoro, 5-Minuten-Regel, Eat the Frog, Body Doubling, Temptation Bundling, Implementation Intentions, …
- ✅ **Aufgaben** mit kleinstem nächsten Schritt, Priorität, Tags, Aufteilung
- 🎯 **Fokus-Session** mit Timer, Atem-Ritual, Ablenkungs-Parkplatz, Umgebungsgeräusch
- 📊 **Insights**: Streaks (mit Grace-Day), XP/Level, Abzeichen, Wochenrückblick, Export/Import
- 🌐 **Zweisprachig** DE/EN, Dark/Light, PWA (offline, installierbar)
- 🔒 **Lokal** – alle Daten bleiben im Browser

## Hosting (GitHub Pages)
1. Repo erstellen, Dateien pushen.
2. Settings → Pages → Source: `main` / root.
3. App unter `https://<user>.github.io/focus-forge/`.

## Lokal starten
Einfach `index.html` im Browser öffnen (oder `npx serve .`).

## Theorie
Prokrastination ist kein Faulheits-, sondern ein Emotionsregulationsproblem (Sirois & Pychyl). FocusForge adressiert die Ursachen: Aufgabenaversivität, Present Bias, Perfektionismus, Überforderung, fehlende Klarheit – über Methoden, Umgebung, Gamification und Selbstmitgefühl.
